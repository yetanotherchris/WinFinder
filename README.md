# WinFinder
A MacOS Finder inspired clone for Windows, written using specs and AI (Gemini 4 Neon), using Rust and Tauri.

## Install

### Windows (Scoop)

```sh
scoop bucket add winfinder https://github.com/yetanotherchris/WinFinder
scoop install winfinder
```

## Development

```sh
npm install
npm run tauri dev
```
